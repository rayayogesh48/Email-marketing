# Reloopin · Email marketing prototype

A frontend-only Next.js application for the supplied email marketing concept. The implementation lives in [`reloopin`](./reloopin).

```bash
npm run dev
```

Open [localhost:3000](http://localhost:3000). Dependencies are already installed. For a fresh checkout, run `npm install --prefix reloopin` first.

```bash
npm run build
npm run lint
npm test
```

See [project documentation](./reloopin/README.md) and [handoff notes](./reloopin/docs/HANDOFF.md).
